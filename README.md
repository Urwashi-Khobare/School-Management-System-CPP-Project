# 🏫 School Management System

A **console-based School Management System developed in C++** that provides separate portals for Admin, Teacher, Student, and Result management. The project demonstrates practical implementation of **Object-Oriented Programming (OOP), CRUD operations, authentication, marks management, and result calculation**.

## ✨ Features

### 👨‍💼 Admin Portal

* Admin registration and login
* Add, update, delete, and view teachers
* Add, update, delete, and view students
* Manage teacher salary
* Search and manage student results

### 👨‍🏫 Teacher Portal

* Teacher registration and login
* Select teaching subject
* Add student marks
* Update internal and examination marks
* View subject-wise student results
* Display pass/fail statistics

### 👨‍🎓 Student Portal

* Student login using Student ID and password
* View personal information
* View complete examination results
* Change password

### 📊 Result Portal

* Search individual student results
* Display all student results
* Edit student marks
* Calculate total marks
* Automatically determine PASS/FAIL status

## 🚀 How to Run

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/school-management-system.git
```

### 2. Open the Project

Open the `.cpp` file in any C++ IDE or code editor such as:

* Visual Studio Code
* Code::Blocks
* Dev-C++
* Visual Studio

### 3. Compile

Using g++:

```bash
g++ main.cpp -o school_management
```

### 4. Run

Windows:

```bash
school_management.exe
```

Linux/macOS:

```bash
./school_management
```
